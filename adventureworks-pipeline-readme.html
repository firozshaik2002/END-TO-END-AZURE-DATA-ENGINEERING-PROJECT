Pipeline Architecture

Medallion Layers

🥉
Bronze Layer Raw ingestion · Azure Data Factory

Dynamically ingests 10 CSV files from GitHub using a metadata-driven Lookup → ForEach pattern. Zero hardcoded paths — fully parameterized pipeline writes raw files to Azure Data Lake Gen2.

Lookup Activity ForEach Loop HTTP Connector ADLS Gen2 Parameterized
🥈
Silver Layer Transformation · Azure Databricks PySpark

PySpark notebooks clean and enrich the raw data. Derived columns FullName, Month, Year are added alongside type casting, SKU normalization, and order number standardization. Output written as Snappy-compressed Parquet.

PySpark Derived Columns Type Casting SKU Normalization Snappy Parquet
🥇
Gold Layer Serving · Azure Synapse Analytics

Synapse serverless SQL exposes Silver Parquet files as views via OPENROWSET. A materialized external table gold.extsales is created using Database Scoped Credentials and Managed Identity for secure, performant BI access.

Serverless SQL OPENROWSET External Tables Managed Identity Scoped Credentials
📊
Analytics Layer Visualization · Power BI

Power BI connects directly to gold.extsales, surfacing monthly order volume trends via line charts — revealing seasonal patterns across the full annual sales cycle.

Power BI Direct Query Line Charts Monthly Trends

Why Medallion

The Medallion Architecture keeps raw data intact in the Bronze layer, making every transformation testable and auditable. Silver handles all enrichment and cleaning logic in isolation, so failures never corrupt source data. The Gold layer stays intentionally thin — just the views and external tables BI tools need — keeping query performance high and the serving surface clean.

Each layer can be reprocessed independently, which makes debugging and backfilling straightforward. For teams learning Azure data engineering, this pattern is a reliable foundation that scales from prototype to production without major restructuring.
